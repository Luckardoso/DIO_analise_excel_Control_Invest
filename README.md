# DIO_analise_excel_Control_Invest
Simulador de investimento em fundos imobiliários, com aporte mensal, prazo em anos e taxa de rendimento mensal.  Me ajude a entender o que cada argumento da função VF faz, e como uma chave composta deixa o PROCV achar o percentual de cada tipo de fundo para cada perfil.

# 📊 Simulador de Investimento Imobiliário

Este projeto foi desenvolvido como parte de um desafio na plataforma **DIO**. Trata-se de uma ferramenta interativa em Excel projetada para simular cenários de investimentos em imóveis, ajudando a calcular a viabilidade financeira e o retorno sobre o capital.
